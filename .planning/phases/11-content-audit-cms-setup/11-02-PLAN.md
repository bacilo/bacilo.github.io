<task type="auto">
  <name>Task 1: Create Sveltia CMS static files and blog collection config</name>
  <files>public/admin/index.html, public/admin/config.yml</files>
  <action>
1. Create `public/admin/index.html` -- the CMS loader page:
   ```html
   <!doctype html>
   <html lang="en">
   <head>
     <meta charset="utf-8">
     <meta name="viewport" content="width=device-width, initial-scale=1.0">
     <title>Content Manager</title>
   </head>
   <body>
     <script src="https://unpkg.com/@sveltia/cms/dist/sveltia-cms.js" type="module"></script>
   </body>
   </html>
   ```

2. Create `public/admin/config.yml` with the following configuration:

   **Backend section:**
   - name: github
   - repo: bacilo/bacilo.github.io
   - branch: master

   **Media folders:**
   - media_folder: "public/images/uploads" (physical save location in repo)
   - public_folder: "/images/uploads" (URL path used in markdown references)
   - IMPORTANT: These MUST be different -- media_folder is repo-relative, public_folder is site-relative

   **Collections -- blog posts:**
   - name: posts
   - label: "Blog Posts"
   - folder: "src/content/posts"
   - create: true (enables BLOG-01: creating new posts)
   - delete: true (enables BLOG-03: deleting posts)
   - slug: "{{year}}-{{month}}-{{day}}-{{slug}}"
   - Fields (mirror src/content.config.ts posts schema EXACTLY):
     - { label: "Title", name: "title", widget: "string", required: true }
     - { label: "Date", name: "date", widget: "datetime", required: true, date_format: "YYYY-MM-DD", time_format: false }
     - { label: "Tags", name: "tags", widget: "list", required: false }
     - { label: "Permalink", name: "permalink", widget: "string", required: false }
     - { label: "Body", name: "body", widget: "markdown", required: true }

   CRITICAL: The body field MUST be named exactly "body" -- this is a Decap/Sveltia convention. If named anything else, the CMS will save markdown content inside the frontmatter YAML block instead of after the --- delimiter.

   Add comments in config.yml linking to content.config.ts:
   ```yaml
   # Schema mirrors src/content.config.ts -- update both when changing fields
   ```

3. Verify the config.yml fields match content.config.ts by checking:
   - title (string) -> widget: string
   - date (z.coerce.date()) -> widget: datetime
   - tags (z.array(z.string()).optional()) -> widget: list, required: false
   - permalink (z.string().optional()) -> widget: string, required: false
   - body -> widget: markdown (not in Zod schema because Astro handles body separately)
  </action>
