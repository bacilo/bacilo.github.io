<task type="auto">
  <name>Task 2: Add FOUC-prevention inline script and themes.css import to BaseLayout</name>
  <files>src/layouts/BaseLayout.astro</files>
  <action>
Modify `src/layouts/BaseLayout.astro` to:

**1. Add inline blocking script in `<head>` BEFORE any stylesheets or other tags (right after `<meta charset>`):**

```html
<script is:inline>
  (function() {
    try {
      var t = localStorage.getItem('site-theme');
      if (t && t !== 'auto' && t !== 'light') {
        document.documentElement.setAttribute('data-theme', t);
      } else if (t === 'auto') {
        if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
          document.documentElement.setAttribute('data-theme', 'auto');
        }
      }
    } catch (e) {}
  })();
</script>
```

Place this script IMMEDIATELY after `<meta charset="UTF-8" />` and BEFORE `<meta name="viewport">`. This ensures theme is applied before the browser paints anything.

Key details about the inline script:
- Uses `is:inline` Astro directive so the code is NOT bundled/deferred — it runs synchronously
- Uses `var` instead of `const`/`let` for maximum browser compatibility in inline context
- Wrapped in IIFE to avoid global scope pollution
- Try/catch handles localStorage unavailability (private browsing)
- For "auto" mode: only sets attribute when system prefers dark (so the CSS media query inside `[data-theme="auto"]` activates)
- For "light" mode: does nothing (no attribute = `:root` defaults = light)
- For any other theme: sets `data-theme` attribute to the theme name

**2. Add themes.css import in the frontmatter section:**

Add `import '../styles/themes.css';` AFTER the existing `import '../styles/global.css';` line. Order matters: themes.css must load after global.css so attribute selectors can override `:root` defaults.

**Do NOT change:**
- Any existing imports, components, or HTML structure
- Any existing `<style>` block
- The `<html lang="en">` tag itself (the script modifies it via JS at runtime)
