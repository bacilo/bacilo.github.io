   - Sort tags by count descending
   - Display each tag as link to /tags/{tag}/ with post count in parentheses
   - Use BaseLayout with title "All Tags"

Use existing permalink generation pattern from posts/index.astro:
```javascript
const permalink = post.data.permalink || (() => {
  const date = post.data.date;
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, '0');
  const postName = post.id.replace(/^\d{4}-\d{2}-\d{2}-/, '').replace(/\.md$/, '');
  return `/posts/${year}/${month}/${postName}/`;
})();
```

Style using existing CSS custom properties (--color-*, --space-*). Match styling patterns from posts/index.astro for consistency.
