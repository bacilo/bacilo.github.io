       - items: mapped posts with title, pubDate, description (first 160 chars), link (permalink), content (sanitized markdown), categories (tags)

Use same permalink generation logic as posts pages:
```javascript
const permalink = post.data.permalink || (() => {
  const date = post.data.date;
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, '0');
  const postName = post.id.replace(/^\d{4}-\d{2}-\d{2}-/, '').replace(/\.md$/, '');
  return `/posts/${year}/${month}/${postName}/`;
})();
```

For content sanitization, allow img tags:
```javascript
content: sanitizeHtml(parser.render(post.body), {
  allowedTags: sanitizeHtml.defaults.allowedTags.concat(['img']),
})
```

For description, extract first paragraph that isn't a heading:
```javascript
const firstParagraph = post.body
  .split('\n\n')
  .find(p => p.trim() && !p.startsWith('#'));
const description = firstParagraph
  ? firstParagraph.substring(0, 160).trim() + '...'
  : post.data.title;
```
