<task type="auto">
  <name>Task 2: Add stone button styling with raised/pressed bevel and reduced-motion guard to minecraft.css</name>
  <files>src/styles/themes/minecraft.css</files>
  <action>
Append a new section to minecraft.css after the inventory slot card rules. Add the following CSS rules, all scoped under `[data-theme="minecraft"]`:

**Section comment:** `/* Stone Buttons (INT-01, INT-02, INT-03) */`

**Raised stone button — normal state** (`.repo-link`, `.link-button`, `.download-link`, `.paper-link a`):
- `background: var(--mc-bg-stone)` (#6b6b6b)
- `border: 2px solid #000000`
- `box-shadow: inset 2px 2px 0 #c6c6c6, inset -2px -2px 0 #373737` (raised 3D bevel: light top-left, dark bottom-right)
- `color: var(--mc-text-light) !important` (force white text)
- `text-shadow: 1px 1px 0 #1a1a1a`
- `font-family: 'Pixelify Sans', monospace`
- `border-radius: 0 !important` (override Astro scoped component styles)
- `text-decoration: none`, `display: inline-block`

**Pressed state — bevel inversion** (`:active` on same selectors):
- `box-shadow: inset 2px 2px 0 #373737, inset -2px -2px 0 #c6c6c6` (inverted: dark on top-left, light on bottom-right = pressed-in effect)

**Tag pills as small stone buttons** (`.tag`):
- `background: var(--mc-bg-stone)`, `border: 1px solid #000000`
- `box-shadow: inset 1px 1px 0 #9a9a9a, inset -1px -1px 0 #373737`
- `color: var(--mc-text-light) !important`, `border-radius: 0 !important`, `text-decoration: none`

**Tag hover** (`.tag:hover`):
- `background: var(--mc-bg-grass)` (green highlight), `border-color: var(--mc-creeper-green)`

**Reduced-motion guard** (`@media (prefers-reduced-motion: no-preference)`):
- Apply `transition: box-shadow 80ms ease, background-color 120ms ease` ONLY inside this media query for `.repo-link`, `.link-button`, `.download-link`, `.paper-link a`, `.tag`
- Also add `transition: border-color 120ms ease, box-shadow 120ms ease` for card hover effects (`.github-card`, `.portfolio-card`) inside the same media query block

Outside this media query, NO transition properties should exist on these elements (instant state changes = accessible by default).
  </action>

  </verify>
