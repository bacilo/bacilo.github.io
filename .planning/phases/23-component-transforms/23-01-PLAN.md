  <action>
Append a new section to minecraft.css after the existing typography rules. Add the following CSS rules, all scoped under `[data-theme="minecraft"]`:

**Hotbar outer container** (`nav:not(.author-links)`):
- `background: #1a1a1a` (dark hotbar frame)
- `border-bottom: 2px solid #000000`
- `padding: 4px 0`

**Hotbar slot list** (`nav:not(.author-links) .nav-list`):
- `background: transparent`, `border: none`, `box-shadow: none`
- `padding: 4px 8px`, `gap: 3px`, `display: flex`

**Individual slots** (`nav:not(.author-links) .nav-list a`):
- `background: var(--mc-bg-stone)` (#6b6b6b)
- `border: 2px solid #000000`
- `box-shadow: inset 2px 2px 0 #9a9a9a, inset -2px -2px 0 #373737` (3D bevel: light top-left, dark bottom-right)
- `color: var(--mc-text-light)`, `text-shadow: 2px 2px 0 #1a1a1a`
- `font-family: 'Pixelify Sans', monospace`
- `padding: 6px 10px`, `border-radius: 0`, `text-decoration: none`, `display: block`
- `border-bottom: none` (remove default active underline from base Navigation.astro styles)

**Active slot highlight** (`nav:not(.author-links) .nav-list a.active`, `nav:not(.author-links) .nav-list a[aria-current="page"]`):
- `background: var(--mc-stone-gray)` (#8b8b8b — lighter slot to stand out)
- `color: #ffffff`
- `box-shadow: inset 2px 2px 0 #e0e0e0, inset -2px -2px 0 #555555, 0 0 6px 1px rgba(255, 255, 255, 0.25)` (inverted bevel + subtle glow)
- `border-color: #c6c6c6`

**Mobile compact layout** (`@media (max-width: 480px)`):
- `.nav-list`: `overflow-x: auto`, `flex-wrap: nowrap`, `padding: 4px`, `gap: 2px`
- `.nav-list a`: `padding: 5px 6px`, `font-size: 11px`, `white-space: nowrap`, `flex-shrink: 0`

Also add a standard desktop `@media (max-width: 768px)` rule to override the base Navigation.astro vertical stacking: keep `flex-direction: row` (horizontal hotbar) but allow wrapping with `flex-wrap: wrap` and tighter gap.

Add clear section comment: `/* Hotbar Navigation (NAV-01, NAV-02, NAV-03) */`
