  <action>
    1. Create directories: `public/images/minecraft/textures/` and `src/styles/themes/`.

    2. Create 6 SVG block texture files, each with a 16x16 viewBox. CRITICAL: every SVG root element MUST have explicit `width="16" height="16"` attributes (not just viewBox) to prevent Firefox blur. Each SVG uses `<rect>` elements for a pixel-grid pattern with color variations:
       - **dirt.svg**: Base #866043, darker #6b4c33 variation pixels, lighter #9a7352 highlight pixels. Follow the exact SVG from research.
       - **stone.svg**: Base #8b8b8b, darker #6b6b6b cracks, lighter #a5a5a5 highlights. Follow research SVG.
       - **grass.svg**: Base #5a8a2f, darker #4a7525 variation, lighter #6da33a highlights. Follow research SVG.
       - **wood.svg**: Base #a57a4c (oak plank brown), darker #8b6340 grain lines as horizontal rect strips at y=3, y=7, y=11, y=15 (1px high, 10-14px wide), lighter #bc9060 highlight pixels scattered.
       - **cobblestone.svg**: Base #7b7b7b, darker #5a5a5a irregular patches (3-4 rect groups simulating rounded stones), lighter #999999 mortar lines between patches.
       - **bedrock.svg**: Base #191919, gray #404040 irregular patches. Follow research SVG.

    3. Create `src/styles/themes/minecraft.css` with the contrast-verified Minecraft color palette. Define all custom properties under `[data-theme="minecraft"]`:
       - Block palette: --mc-dirt-brown (#866043), --mc-grass-green (#5a8a2f), --mc-stone-gray (#8b8b8b), --mc-sky-blue (#64b8d4), --mc-creeper-green (#55a715)
       - Semantic backgrounds (WCAG AA verified): --mc-bg-grass (#2f5a1e, 8.07:1 vs white), --mc-bg-stone (#6b6b6b, 5.33:1 vs white), --mc-bg-dark (#1a1a1a, 17.40:1 vs white), --mc-bg-darkest (#0d0d0d), --mc-bg-dirt (#614228, 9.06:1 vs white)
       - Text colors: --mc-text-light (#ffffff), --mc-text-cream (#f5f5dc), --mc-text-muted (#c8c8c8), --mc-text-dark (#1a1a1a)
       - Semantic variable overrides: --color-bg: var(--mc-bg-grass), --color-text: var(--mc-text-light), --color-text-muted: var(--mc-text-muted), --color-link: var(--mc-sky-blue), --color-link-hover: #87ceeb, --color-border: var(--mc-dirt-brown), --color-header-bg: var(--mc-bg-dirt)

    4. In the same minecraft.css, add section-specific texture background assignments. Use `[data-theme="minecraft"]` prefix on EVERY rule. Apply `image-rendering: pixelated; image-rendering: crisp-edges;` on every textured element. Use `background-size: 64px 64px` (4x the 16px native size) and `background-repeat: repeat`:
       - body: grass.svg (overworld surface) with solid --mc-bg-grass fallback color
       - .site-header: dirt.svg
       - nav: stone.svg
       - .author-sidebar: wood.svg
       - main: NO texture (solid --mc-bg-dark background-color for readability per research recommendation — textures on text content hurt readability)
       - footer: bedrock.svg

    Note: Do NOT add font rules yet — that is Plan 02. Do NOT add text-shadow yet — that is Plan 02.
  </action>
  <verify>

    - minecraft.css exists and contains [data-theme="minecraft"] with all --mc-* and --color-* variables
    - minecraft.css contains background-image rules referencing all 6 SVG textures
    - minecraft.css contains image-rendering: pixelated on every textured element
    - Run `npx astro check` to confirm no build errors
  </verify>
