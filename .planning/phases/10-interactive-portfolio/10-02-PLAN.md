**DemoEmbed.astro:**
Per research Pattern 2 - Responsive Iframe with Lazy Loading.

Props: { src: string, title: string, aspectRatio?: string }
Default aspectRatio: "16/9"

Structure:
```html
<div class="demo-embed-container">
  <iframe
    src={src}
    title={title}
    loading="lazy"
    sandbox="allow-scripts"
    class="demo-iframe"
  ></iframe>
</div>
```

Note: Use `sandbox="allow-scripts"` only (NOT allow-scripts + allow-same-origin together per security research).

Styles using define:vars for aspectRatio:
- Container: width 100%, aspect-ratio from var, border, border-radius 8px, overflow hidden
- Iframe: width 100%, height 100%, border none
- Mobile media query (max-width: 768px): aspect-ratio 1/1 for better mobile viewing
- Use CSS custom properties for border color

**PlaygroundEmbed.astro:**
Per research Pattern 3 - Code Playground Embed with Platform Detection.

Props: { url: string, title: string }

Platform detection from URL:
- CodePen: url.includes('codepen.io')
- StackBlitz: url.includes('stackblitz.com')
- JSFiddle: url.includes('jsfiddle.net')

URL transformation to embed format:
- CodePen: replace '/pen/' with '/embed/' and add '?default-tab=result'
- StackBlitz: append '?embed=1&hideExplorer=1&view=preview'
- JSFiddle: append '/embedded/result,js,html,css/'

Structure:
```html
<div class="playground-embed">
  <iframe
    src={embedUrl}
    title={title}
    loading="lazy"
    sandbox="allow-scripts allow-forms allow-popups"
    class="playground-iframe"
  ></iframe>
</div>
```

Note: sandbox includes allow-forms and allow-popups for playground functionality, but NOT allow-same-origin.

Styles:
- Container: width 100%, aspect-ratio 16/9, border, border-radius 8px, overflow hidden, background header-bg
- Iframe: width 100%, height 100%, border none
- Mobile: aspect-ratio 4/3
