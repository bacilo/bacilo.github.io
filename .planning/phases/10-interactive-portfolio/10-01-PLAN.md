  <action>
Create TypeScript module for client-side GitHub API fetching.

Interface GitHubRepo with: name, description (string | null), stargazers_count (number), language (string | null), html_url (string).

Function fetchRepoData(owner: string, repo: string): Promise<GitHubRepo | null>:
1. Build URL: `https://api.github.com/repos/${owner}/${repo}`
2. Use AbortController with 5-second timeout
3. Set Accept header: 'application/vnd.github.v3+json'
4. Handle rate limiting (403/429): Log warning with reset time from x-ratelimit-reset header, return null
5. Handle other errors: Log to console, return null
6. On success: Return parsed JSON

Add 1-hour localStorage caching:
- Cache key: `github-repo-${owner}-${repo}`
- Cache format: { data: GitHubRepo, timestamp: number }
- Check cache before fetch, return cached if < 1 hour old
- Update cache after successful fetch

Export fetchRepoData function.

Reference research Pattern 1 for exact implementation details.

**GitHubCard.astro:**
Props interface: { repoUrl: string, title: string, description?: string }

Parse owner/repo from repoUrl using regex: `/github\.com\/([^/]+)\/([^/]+)/`

Render structure:
```html
<div class="github-card" data-owner={owner} data-repo={repo}>
  <div class="skeleton-wrapper">
    <SkeletonCard />
  </div>
  <div class="content" style="display: none;">
    <h2 class="repo-name">{title}</h2>
    <p class="repo-desc">{description or 'No description'}</p>
    <div class="repo-stats">
      <span class="stars">Stars: <span class="star-count">-</span></span>
      <span class="language">Language: <span class="lang-value">-</span></span>
    </div>
    <a href={repoUrl} class="repo-link">View on GitHub</a>
  </div>
</div>
```

Client-side script (inside <script> tag):
- Import fetchRepoData from '../../scripts/github-api'
- On DOMContentLoaded, query all .github-card elements
- For each card: get data-owner/data-repo, call fetchRepoData
- On success: populate .repo-desc, .star-count (toLocaleString), .lang-value
- On failure: keep original description, show "Unable to load stats" for stats
- Hide .skeleton-wrapper, show .content

Style card matching existing portfolio-card design:

- Same hover/focus-within states
