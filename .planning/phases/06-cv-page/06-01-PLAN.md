Structure the CV with these sections:

1. **Page header:**
   - h1: "Curriculum Vitae"
   - Brief intro paragraph about the CV

2. **Education section:**
   - h2: "Education"
   - Use definition list (dl/dt/dd) or structured divs for entries
   - Each entry: degree, institution, year, optional description
   - Include 2-3 placeholder entries the user can replace

3. **Work Experience section:**
   - h2: "Work Experience"
   - Each entry: position, organization, date range, responsibilities
   - Include 2-3 placeholder entries

4. **Skills section:**
   - h2: "Skills"
   - Bulleted list organized by category
   - Include placeholder categories (Research Methods, Technical, etc.)

5. **Publications section:**
   - h2: "Publications"
   - Single paragraph: "See my complete list of [publications](/publications/)."
   - Do NOT try to embed the publications list

6. **Talks section:**
   - h2: "Talks"
   - Single paragraph: "See my complete list of [talks](/talks/)."
   - Do NOT try to embed the talks list

7. **Teaching section:**
   - h2: "Teaching"
   - List format for courses taught
   - Include 2-3 placeholder entries

8. **Service section:**
   - h2: "Service and Leadership"
   - List format for committee work, reviewing, etc.
   - Include 2-3 placeholder entries

Styling (scoped CSS):

- Use existing CSS custom properties (--space-*, --color-*)
- Section spacing: margin-bottom: var(--space-lg)
- h2 headings: border-bottom: 1px solid var(--color-border), padding-bottom: var(--space-xs), margin-bottom: var(--space-md)
- CV entries use .cv-entry class with margin-bottom: var(--space-md)
- Entry titles (.cv-entry-title): font-weight: bold
- Entry details (.cv-entry-details): color: var(--color-text-muted)
- Lists: standard ul/li with default bullets

Keep the page simple and scannable. Academic CVs prioritize clarity over visual complexity.
