# Milestone v2.0: Content Management

**Status:** SHIPPED 2026-02-13
**Phases:** 11-13
**Total Plans:** 6

## Overview

Enable web-based content editing through Sveltia CMS so updates feel effortless instead of requiring IDE workflow. Deployed Sveltia CMS as static files at /admin with GitHub PAT authentication, configured all 4 content collections (blog, publications, talks, portfolio) for full CRUD operations, and validated production readiness across Chrome, Firefox, and Safari.

## Phases

### Phase 11: Content Audit & CMS Setup

**Goal**: CMS admin interface functional with blog posts editable
**Depends on**: Phase 10
**Plans**: 2 plans

Plans:
- [x] 11-01: Content audit & frontmatter normalization — All 5 blog posts validated against Zod schema with automated audit script
- [x] 11-02: CMS static setup & blog collection with PAT auth — Sveltia CMS deployed at /admin with GitHub PAT authentication and blog CRUD

## Milestone Summary

**Key Decisions:**
- Sveltia CMS over Decap CMS (modern successor, PAT auth built-in) — Good
- PAT authentication over OAuth (simplest for single user, no server) — Good
- Static CMS hosting in public/admin/ (no SSR adapter) — Good
- Schema synchronization via comments linking config.yml to content.config.ts — Good
- gray-matter for frontmatter parsing (industry-standard, CI-ready) — Good
- Widget "text" for multi-line content (not "string") — Good

**Issues Resolved:**
- All 26 content files validated against Zod schemas (no violations found)
- Dev server /admin/ path resolved (use /admin/index.html in dev, /admin/ in production)
- Sveltia CMS saving indicator persists after save (documented as upstream behavior)

**Issues Deferred:**
- Custom preview templates (CMS-04) — deferred to future milestone
- Editorial workflow with draft/publish (CMS-05) — deferred to future milestone
- Custom widgets for DOI/citation fields (CMS-06) — deferred to future milestone

**Technical Debt Incurred:**
- Schema synchronization between content.config.ts and config.yml is manual (documented in user guide)
- Image optimization not handled by CMS (manual workflow acceptable for now)
