  <action>
Create `src/scripts/copy-code.ts` with:

**`initCopyButtons()` exported function:**

1. Find all `.astro-code` elements using `document.querySelectorAll<HTMLPreElement>('.astro-code')`
2. For each code block:
   a. Check if parent already has a `.copy-button` — skip if so (idempotent)
   b. Get the text content of the `<pre>` element: `codeBlock.textContent || ''`
   c. Create a wrapper `<div class="code-block-wrapper">` with `position: relative`
   d. Wrap the `<pre>` element: insert wrapper before pre, then move pre inside wrapper
   e. Create a `<button>` element with:
      - `className = 'copy-button'`
      - `type = 'button'`
      - `setAttribute('aria-label', 'Copy code to clipboard')`
      - `textContent = 'Copy'`
   f. Insert button as first child of wrapper (before the pre)
   g. Add click event listener (async) that:
      - Reads code text from the pre element's textContent (not from a data attribute — ensures code is always current)
      - Calls `navigator.clipboard.writeText(code)`
      - On success: set button text to 'Copied!', add class 'copy-success', update aria-label to 'Code copied to clipboard'
      - On error: log to console, set button text to 'Failed', add class 'copy-error'
      - After 2000ms: reset button text to 'Copy', remove success/error class, restore aria-label

**CSS injection (via a `<style>` block in the script or via the wrapper component):**

Since this is a standalone script (not an Astro component), inject styles by checking if they already exist and adding a `<style>` element to `<head>` if not:


Key design decisions:
- Button hidden by default (opacity: 0), shown on hover over wrapper or focus — keeps code blocks clean
- Uses existing CSS custom properties (--color-header-bg, --color-text-muted, --color-border, --color-link) so button adapts to all 8 themes
- Success/error colors are hardcoded green/red since they're universal semantic colors
- z-index: 10 ensures button renders above code content
