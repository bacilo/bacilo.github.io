<task type="auto">
  <name>Task 2: Render widget embeds on portfolio index page</name>
  <files>src/pages/portfolio/index.astro</files>
  <action>
Update `src/pages/portfolio/index.astro` to render CodePen and StackBlitz embeds when portfolio items have embed IDs configured.

The existing `PlaygroundEmbed.astro` component already handles CodePen and StackBlitz URL transformation (converts pen URLs to embed URLs, adds StackBlitz embed params). Reuse it by constructing URLs from the IDs.

In the portfolio index template, after the existing `PlaygroundEmbed` conditional block (which renders based on `playgroundUrl`), add:

```astro
{project.data.codepenId && (
  <PlaygroundEmbed
    url={`https://codepen.io/pen/${project.data.codepenId}`}
    title={`${project.data.title} Demo`}
  />
)}
{project.data.stackblitzId && (
  <PlaygroundEmbed
    url={`https://stackblitz.com/edit/${project.data.stackblitzId}`}
    title={`${project.data.title} Editor`}
  />
)}
```

This reuses the existing `PlaygroundEmbed` component which already:
- Transforms CodePen `/pen/` URLs to `/embed/` with `?default-tab=result`
- Adds StackBlitz `?embed=1&hideExplorer=1&view=preview` params
- Has responsive iframe styling with 16:9 aspect ratio (4:3 on mobile)
- Uses lazy loading and sandbox attributes

No new component needed -- `PlaygroundEmbed` handles the URL transformation and rendering. The codepenId/stackblitzId fields simply provide a more direct way to configure embeds than full URLs (which `playgroundUrl` already supports).
  </action>
  <verify>Run `npx astro build` to confirm no errors. Check the rendered HTML of /portfolio/ to verify no embed iframes appear for items without codepenId/stackblitzId (which is all current items). The embed rendering is structurally correct and will activate when content authors add IDs to portfolio items.</verify>
  <done>Portfolio index renders CodePen/StackBlitz iframes for items with configured embed IDs, using the existing PlaygroundEmbed component for URL transformation and responsive iframe display. Items without embed IDs show no embed.</done>
