Run a paired Lighthouse measurement to verify QUAL-03 (Minecraft theme performance within 10 points of no-theme baseline).

**CRITICAL: Lighthouse headless Chrome does NOT read localStorage, so the Minecraft theme must be hardcoded for the themed run.**

**Step 1: Read and save the original BaseLayout.astro inline script** (lines 37-49 approximately). Save the exact content so it can be reverted precisely.

**Step 2: Start the Astro dev server**
```bash
npx astro dev &
sleep 8  # wait for server to fully start
```

**Step 3: Run no-theme baseline Lighthouse**
BaseLayout.astro is unmodified — headless Chrome starts with empty localStorage, so no theme is applied (default light theme).
```bash
npx lighthouse http://localhost:4321/ \
  --output=json \
  --output-path=./lighthouse-notheme.json \
  --only-categories=performance \
  --chrome-flags="--headless --no-sandbox" \
  --quiet
```

**Step 4: Temporarily hardcode Minecraft theme in BaseLayout.astro**
Replace the inline script content (the IIFE inside `<script is:inline>`) with:
```javascript
(function() {
  document.documentElement.setAttribute('data-theme', 'minecraft');
})();
```
This forces the Minecraft theme for all visitors including headless Chrome.

**Step 5: Wait for Astro hot-reload** (sleep 5 seconds for the dev server to pick up the change).

**Step 6: Run Minecraft-themed Lighthouse**
```bash
npx lighthouse http://localhost:4321/ \
  --output=json \
  --output-path=./lighthouse-minecraft.json \
  --only-categories=performance \
  --chrome-flags="--headless --no-sandbox" \
  --quiet
```

**Step 7: IMMEDIATELY revert BaseLayout.astro** to the exact original inline script saved in Step 1. This is critical — do NOT leave the hardcoded theme in place.

**Step 8: Stop the dev server** (kill the background process).

**Step 9: Extract and compare scores**
```python
import json
b = json.load(open('lighthouse-notheme.json'))
m = json.load(open('lighthouse-minecraft.json'))
baseline = round(b['categories']['performance']['score'] * 100)
mc = round(m['categories']['performance']['score'] * 100)
diff = baseline - mc
print(f'No-theme baseline: {baseline}/100')
print(f'Minecraft theme:   {mc}/100')
print(f'Delta: {diff} points')
print(f'QUAL-03: {"PASS" if abs(diff) <= 10 else "FAIL"}')
```
