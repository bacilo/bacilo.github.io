# Requirements: Personal Website v3.0

**Defined:** 2026-02-16
**Core Value:** A professional online presence that showcases work and is easy to maintain with monthly content updates

## v3.0 Requirements

Requirements for this milestone. Each maps to roadmap phases.

### Code Embeds

- [x] **CODE-01**: Portfolio cards display syntax-highlighted code snippets with Shiki at build time — Delivered via Phase 15
- [x] **CODE-02**: Code snippets include a copy-to-clipboard button — Delivered via Phase 16
- [x] **CODE-03**: Portfolio cards can embed runnable widget iframes (CodePen, StackBlitz, etc.) — Delivered via Phase 17
- [x] **CODE-04**: Astro's built-in Shiki is configured site-wide for markdown code fences — Delivered via Phase 15

### Portfolio Stats

- [x] **STAT-01**: Each portfolio item can configure stats display (stars, downloads, both, or none) via frontmatter — Delivered via Phase 17
- [x] **STAT-02**: Portfolio cards fetch and display release download counts from GitHub Releases API — Delivered via Phase 17
- [x] **STAT-03**: Stats display configuration is editable via Sveltia CMS — Delivered via Phase 17

### Theme System

- [x] **THEME-01**: Site offers 8 switchable CSS themes: auto, light, dark, sepia, retro terminal, Minecraft/pixel, Lego/bold, synthwave — Delivered via Phase 14
- [x] **THEME-02**: User can switch themes via a dropdown in footer or sidebar — Delivered via Phase 16
- [x] **THEME-03**: Selected theme persists across page loads via localStorage — Delivered via Phase 16
- [x] **THEME-04**: Theme applies before first paint (no flash of unstyled content) — Delivered via Phase 14
- [x] **THEME-05**: Auto theme respects system prefers-color-scheme preference — Delivered via Phase 14

## Out of Scope

| Feature | Reason |
|---------|--------|
| Runnable code execution (eval/Function) | Security risk (XSS/CSP), use iframe sandboxes instead |
| React/Svelte syntax highlighters | Shiki built into Astro, no framework needed |
| CSS-in-JS theme libraries | CSS custom properties sufficient, no framework needed |
| Octokit packages | Native fetch matches existing pattern, avoids 300KB dependency |
| Build-time GitHub pre-fetching | Client-side with cache works for current scale |
| Multi-user theme preferences | Single user site, localStorage sufficient |
