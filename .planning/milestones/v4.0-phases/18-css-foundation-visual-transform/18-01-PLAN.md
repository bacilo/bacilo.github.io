<task type="auto">
  <name>Task 3: Hide mobile sidebar on non-Home pages</name>
  <files>src/layouts/BaseLayout.astro, src/styles/global.css</files>
  <action>
**1. Add `page-home` class to body in BaseLayout.astro:**

In the `<body>` tag (currently just `<body>`), add a conditional class using Astro's class:list directive:

```astro
<body class:list={[{ 'page-home': Astro.url.pathname === '/' }]}>
```

This adds `class="page-home"` to the body only on the Home page (`/`).

**2. Add mobile sidebar hiding rules to global.css:**

Add at the bottom of global.css, after the `.sr-only` block:

```css
/* Mobile sidebar visibility (RESP-01)
 * Hide sidebar on mobile for all pages except Home.
 * Sidebar is always visible on desktop (>768px).
 */
@media (max-width: 768px) {
  .author-sidebar {
    display: none;
  }

  body.page-home .author-sidebar {
    display: block;
  }
}
```

The hide rule comes first, then the Home exception overrides it via higher specificity (`body.page-home .author-sidebar` > `.author-sidebar`). This is placed in global.css (not themes.css) because it applies to ALL themes, not just LEGO.

**Note:** The AuthorSidebar.astro component already has `width: 100%` on mobile and `width: 250px` on desktop via its scoped styles. The new global.css rules control visibility only. No changes needed to AuthorSidebar.astro.
