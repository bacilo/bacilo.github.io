# Requirements: Personal Website Rebuild

**Defined:** 2026-02-11
**Core Value:** A professional online presence that showcases work and is easy to maintain

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Academic Content

- [ ] **ACAD-01**: User can view publications listing with title, venue, date, citation
- [ ] **ACAD-02**: Each publication has link to PDF or external paper
- [ ] **ACAD-03**: User can view talks listing with date, venue, location
- [ ] **ACAD-04**: Each talk has link to slides or recording
- [ ] **ACAD-05**: User can view CV page with academic history

### Author Profile

- [ ] **AUTH-01**: Author sidebar displays photo, name, bio
- [ ] **AUTH-02**: Author sidebar includes social links (Twitter, LinkedIn, GitHub)
- [ ] **AUTH-03**: Author sidebar includes academic links (Google Scholar, ORCID)
- [ ] **AUTH-04**: About/home page displays author introduction

### Blog

- [ ] **BLOG-01**: User can view blog posts with full content
- [ ] **BLOG-02**: Blog posts have tags for categorization
- [ ] **BLOG-03**: User can browse posts chronologically (archive)
- [ ] **BLOG-04**: User can filter posts by tag
- [ ] **BLOG-05**: User can filter posts by category
- [ ] **BLOG-06**: Site provides RSS feed for blog subscription

### Portfolio

- [ ] **PORT-01**: User can view portfolio page with project cards
- [ ] **PORT-02**: Each project card shows title, description, links
- [ ] **PORT-03**: GitHub repo cards display stars, language, description from API
- [ ] **PORT-04**: Portfolio supports live demo embeds (iframe-based)
- [ ] **PORT-05**: Portfolio supports code playground embeds

### Navigation & Design

- [ ] **NAV-01**: Site has navigation with links to all sections
- [ ] **NAV-02**: Site is responsive (works on mobile and desktop)
- [ ] **NAV-03**: Design maintains clean academic aesthetic
- [ ] **NAV-04**: URL structure preserved from Jekyll site (no broken links)

### Infrastructure

- [ ] **INFR-01**: Site built with Astro static site generator
- [ ] **INFR-02**: Site deploys to GitHub Pages automatically
- [ ] **INFR-03**: Content authored in markdown with frontmatter
- [ ] **INFR-04**: Existing Jekyll content migrated successfully

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Enhanced Portfolio

- **PORT-06**: Data visualization embeds (charts, interactive graphics)
- **PORT-07**: Filtering/sorting of portfolio projects

### Content Enhancements

- **CONT-01**: Dark mode toggle
- **CONT-02**: Search functionality
- **CONT-03**: Analytics integration

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Teaching section | Not needed for current goals |
| Comments system | Complexity not worth it for monthly updates |
| Custom domain setup | Sticking with bacilo.github.io |
| Auto-import from Google Scholar | Academics need manual curation control |
| Real-time GitHub stats | Build-time fetch sufficient, avoids rate limits |
